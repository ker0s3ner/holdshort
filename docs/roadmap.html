Roadmap

Holdshort is a hobby project built in public, released frequently. This page is a rough sense of direction, not a promise — things move around based on what breaks, what gets requested, and what turns out to be more interesting than planned.

Shipped recently
  • A real Approach position — arrivals fly a ~18nm final with a real altitude/speed/heading profile instead of spawning straight onto the runway, vectoring clearances (heading, altitude, speed, cleared approach), a CRC-style abbreviated command entry, and its own range-ring radar scope
  • Real position separation — ground can't issue a takeoff clearance just because the button exists; the backend checks who's actually responsible for an aircraft in its current phase
  • Multi-runway Tower: several runway ends active at once, each independently serving departures, arrivals, or both
  • CRC / EuroScope themes, now wired into the SMR and Tower Cab canvases themselves (not just the app chrome)
  • A real plugin SDK — a sandboxed iframe with a live read-only telemetry feed, not a built-in toggle pretending to be a plugin. See Plugins
  • Voice commands auto-select the aircraft named in the transmission, the way a real controller's clearance always includes the callsign
Next
  • Sequencing/spacing between arrivals on approach — today each flies its own final independently
  • A write API for plugins — issuing clearances from plugin code, not just reading telemetry (a real sandboxing/trust problem on its own)
  • More airports and countries, prioritized by request
  • Richer flight-strip/flight-plan data (squawk, route, remarks)
Later
  • Center/en-route control, beyond the terminal area Approach now covers — a genuinely separate simulation domain (navaids, airways, sector boundaries), not an extension of what exists
  • Shared multiplayer sessions (a VATSIM-style shared network between separate Holdshort instances) — the World Traffic Map plugin is a preview of what this could look like, but today it only sees your own local session
  • Windows build
  • Paid Apple Developer signing, once the project can justify the cost

Have a request?

Open an issue on GitHub — specific airport requests, bug reports, and feature ideas are all welcome.
