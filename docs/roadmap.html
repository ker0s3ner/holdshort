Roadmap

Holdshort is a hobby project built in public, released frequently. This page is a rough sense of direction, not a promise — things move around based on what breaks, what gets requested, and what turns out to be more interesting than planned.

Now
  • More accurate speech recognition (model ladder, ATC vocabulary biasing)
  • CRC / EuroScope visual themes for the app chrome
  • Cleaner Settings (Voice, Themes, Plugins as separate tabs)
  • Visually distinguishing runways from taxiways across every view
Next
  • Playable Approach position (currently a read-only preview)
  • A real third-party plugin runtime — sandboxed, not just built-in toggles
  • More airports and countries, prioritized by request
  • Theming extended to the SMR / Tower Cab canvas rendering itself
  • This website: richer plugin directory once there's something to list
Later
  • Shared multiplayer sessions (a VATSIM-style shared network between separate Holdshort instances) — the built-in World Traffic Map plugin is a preview of what this could look like, but today it only sees your own local session
  • Windows build
  • Full Control/Departure position, beyond Ramp/Ground/Tower
  • Paid Apple Developer signing, once the project can justify the cost

Have a request?

Open an issue on GitHub — specific airport requests, bug reports, and feature ideas are all welcome.

Holdshort is a free, open-source hobby project.
