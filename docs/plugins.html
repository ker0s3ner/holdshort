Plugins

Plugins are extras you switch on from Settings → Plugins, built around the same on/off pattern a future community plugin system would use.

There's no sandboxed runtime for loading third-party plugin code yet — safely running code someone else wrote is a real engineering project of its own. So for now, "plugins" means a small set of built-in extras rather than an "install from URL" box that doesn't actually do anything. A real third-party plugin SDK is on the roadmap.

World Traffic Map

A VatSpy-style world map showing where each aircraft in your current session is really flying to or from. It only knows about traffic in your own local sim — there's no shared network connecting separate Holdshort sessions together yet, so it can't show other players. That's the kind of thing a future community plugin (or built-in multiplayer, see the roadmap) could change.

Building your own

There isn't a public plugin API to build against yet. If you've got an idea for one — a shared network layer, alternate traffic sources, custom airport packs — open a discussion on GitHub. What ships first here will likely be shaped by what people actually ask for.
